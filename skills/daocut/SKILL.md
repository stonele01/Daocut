# Daocut

Run the installed `daocut` command and follow the manual it prints. Use the command bundled with the Daocut desktop
app; do not install another copy with npx. If it is unavailable, report that instead of installing software.
Inside the desktop chat, Studio is already open: do not run `daocut open` or open another browser.
