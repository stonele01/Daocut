# 大视频播放恢复 · 0.2.55

本版包含 [0.2.54 的打开优化](DAOCUT-LARGE-VIDEO-OPEN-0.2.54-20261115.md)，并修复原片播放器遇到媒体网络读取错误后无法自动恢复的问题。

## 行为

- 仅对 MEDIA_ERR_NETWORK 自动重连，最多两次；保留位置和播放意图，并显示重试次数。
- 重连期间拖动或选择其他片段，以最后一次操作为准；手动暂停不会被迟到的加载完成事件重新播放。
- 次数用完后显示读取错误，用户再次点播放可以重试。解码及格式错误不循环重试。
- 媒体信息尚未到达时拖动，加载完成后应用用户选定的位置。

## 验证范围

以网络盘大视频进行真实界面点击播放、前后拖动、时间轴跳转和暂停测试。向验收页的一次媒体请求注入 HTTP 503，浏览器实际报出 MEDIA_ERR_NETWORK / PIPELINE_ERROR_READ；应用自动恢复并从原位置继续播放。所有注入在测试后撤销。原始媒体元数据及详细观测保存在本地。

使用生产 Studio 界面连接实际后端完成操作；原生窗口自动化不可用。本轮不是整场视频持续播放或成片播放器的完整验收。历史空响应的具体拦截层仍未确定，不能把它归因为某个第三方软件。

- 播放浏览器回归 16 项通过，覆盖晚到元数据、拖动、暂停、旧播放请求拒绝、重连上限及真实 H.264/AAC 解码。
- Studio 前端 TypeScript 检查通过。
- 大素材身份、打开进度、采样引用备份回归 32 项通过；针对性检查已加入 CI。
- 发行包逐文件核对已验收代码及界面。安装器和公司更新通道继续走现有内容核验与客户端下载校验流程。

其他已有测试限制见 0.2.54 记录。
